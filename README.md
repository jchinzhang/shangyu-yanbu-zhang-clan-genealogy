# 上虞雁埠章氏宗谱 · 数字整理全集

《**上虞雁埠章氏宗谱**》——星聚堂 · 木活字本 · **民国十四年乙丑（1925）**
十六卷、首一卷、末一卷，闰集二卷，共 **十三册 · 2237 页**。

本仓库为**个人家族文献的数字化整理与接谱考证存档**，含原书影像、古籍 OCR 文字档、
世次与人名索引，以及近年所做的谱外史料互证。
